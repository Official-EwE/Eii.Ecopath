5.12 Tools menu

Options…

The Options menu item opens a dialogue box containing the following features that allow you to set your preferences for using the software. The window on the left of the Options dialogue box contains a menu with two nodes: Application and Model. Click on the “+” buttons to expand the nodes.

Application

Change settings that apply to the general appearance and behaviour of the software.

General

Recent files

Set the number of  recently-used files to display on the File menu. You can also clear the recently-used file list using the Clear history button.

Window layout

A feature of the EwE 6.0 is the ability to customize the appearance (layout) of the Graphic User Interface (GUI) by dragging and docking any of the windows (see General features of the Graphic User Interface). Checking the Save windows layout box saves changes to the appearance of the GUI for the next time the model is opened. Unchecking the box means that the model will be re-opened with the default layout. You can also set where the layout file is saved by typing it directly or using the browse […] button. Note that a different layout file is saved for each model.

Message display

Select Message to set the way that critical messages, warning messages and information messages are displayed (i.e., as a pop-up message; in the Status panel; or as a pop-up message in the Status panel).

Color

The Color options allow you to set the colors for a large number of components of the model and GUI.

Units

There are two basic choices for the ‘currency’ of your model: energy-related units (which imply a respiration term), and nutrient-related units (which imply no respiration term). Only models constructed using an energy-related currency (t·km2·year-1) can be run under Ecosim and Ecospace.

Selection of the time unit does not influence any of the calculations in Ecopath (except for determining whether Ecosim/Ecospace can be assessed or not, see above). It affects only the labels on tops of the output forms, etc.

Use the Units interface to set the Energy, Time and Nutrients units used in your model. Default units for energy and time are wet weight (t·km2) and year respectively.

Model

Change settings that apply to the current model.

General

You can set the number of relevant decimal digits to be displayed. Relevant decimal digits are defined as digits that occur after the first non-zero decimal place. For example, if the number of relevant decimal digits is set to three, 0.3654 would be displayed as 0.365 and 0.0003654 would be displayed as 0.000365. Note that this is for display only and no rounding actually occurs in the running of the model. Double-clicking a number in a cell to edit it shows all the decimal places used in the calculations.

NOTE: For values calculated by the model (displayed in yellow-shaded cells, e.g., the Sum of the prey proportions in the Diet matrix) the number you set in this box will be used to set number of decimal places.

Color

Use this window to set the colors for individual model-groups. These colors will be displayed in Ecosim and Ecospace output plots.
