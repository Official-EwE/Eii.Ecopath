11 Using Ecospace. Part 2: Ecospace outputs

Once you have set up your Ecospace scenario(s) using the Ecospace input forms, you can test your model’s predictions using Ecospace. This chapter describes the form used to run Ecospace (Run Ecospace).

Before using Ecospace, we recommend you read the introductory material on Ecospace (see links in Introductory material Ecospace, also found in Chapter 4 of the User Guide). You should also be familiar with the published literature on Ecospace, particularly Walters et al. 1999).
