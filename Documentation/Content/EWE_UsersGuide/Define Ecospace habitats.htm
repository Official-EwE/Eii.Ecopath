10.3 Define Ecospace habitats

‘Habitats’, in Ecospace, are sets of (water) cells sharing certain features affecting the movements, feeding rate, and survival of the Ecopath model components occurring therein. Any number of user defined habitats can be used in Ecospace along with the catch-all habitat no. 1, called ‘All habitats’.

Typically, the features defining habitats are distance from the coast (inshore, offshore…), or depth (shallow, intermediate, deep…) and/or bottom type (rocky, sandy, muddy…). Habitats are thus as easy to define as it is to obtain rough bathymetric maps or maps indicating bottom types.

Ideally, the habitats defined in Ecospace should correspond to ‘sub-web’, i.e., to a set of primary producers, herbivorous and other consumers occurring only over that habitat.  Such sub-webs, defined through the diet composition matrix of an Ecopath file may be linked, through higher trophic levels groups, with other sub-webs in the same system, as also occurs in nature. Herein, the higher trophic level groups, through their ability to feed in different habitats, integrate the different subsystem into a whole.

Assuming that such sub-webs are implicit in the Ecopath file underlying an Ecospace analysis, all that is needed is, thus to give names – preferably short and descriptive – to the habitat types in question, using the Edit habitats dialogue box (see below).  Habitats can be set as MPAs for all or part of the year, using the Edit MPAs dialogue box (see below). Users can also define regions, using the Edit Regions dialogue box (see below).

Note organisms at the upper trophic levels, (i.e., nekton) due to their high mobility will tend to ‘prefer’ a wide range of habitats rather than a specific one.  The habitat name ‘All’ should be used for organisms ranging across all habitat types.

Also note that definition of habitat in Ecospace usually includes the entire water column, from the surface to the bottom.  Thus, while ‘rockfishes’ will tend to be limited to hard bottoms, and burrowing bivalves to soft bottoms, small coastal pelagics, which occur higher up in the water column, may ‘prefer’ hard and soft bottom habitats, as long as both are coastal.

To facilitate documentation of an Ecospace scenario, space is provided to add, besides the (short) name of each habitat, a longer definition, e.g., as taken from some published description.

Edit habitats

Habitats are defined using Edit habitats dialogue box, accesible from the Ecospace Basemap form or directly from the Ecospace menu  (Figure 10.3). Any number of user defined habitats can be used in Ecospace along with the catch-all habitat No. 1, called ‘All’. Type the number of habitats in the Define number of habitats box then click Update # habitats. Type names for the habitats in the appropriate cells. After you have assigned the habitats to the base map using Assign habitats form the fractions of each habitat will be updated automatically.

Edit MPAs

Users can overlay habitats with designated marine protected areas (MPAs). MPAs are defined using Edit MPAs dialogue box, accesible from the Ecospace Basemap form or directly from the Ecospace menu (Figure 10.4). Type the number of MPAs in the Define number of MPAs box then click Update # MPAs. MPAs will automatically be named MPA1, MPA2 etc. They can be renamed by typing directly in the name cell.

You can simulate seasonal MPAs by setting the months of the year that the MPA is operational in the check boxes provided. Use the Ecospace fishery form to assign which fleets can and cannot fish in the MPA. Assign the MPAs to the base map using the Basemap form.

Edit regions

Users can also overlay habitats with statistical ‘regions’ (i.e., groups of cells). Regions represent areas of management interest and may or may not have biological significance. Organisms cannot be assigned to regions, only habitats.

Regions are defined using Edit regions dialogue box, accesible from the Ecospace Basemap form or directly from the Ecospace menu (Figure 10.5). Type the number of regions in the Define number of regions box then click Update # regions.  Regions will automatically be named Region1, Region2 etc. They can be renamed by typing directly in the name cell. Assign the regions to the base map using the Basemap form.

To set each habitat as a region, click the Habitat = regions button on the Edit regions dialogue box. In this case, the regions will automatically be updated on the basemap to be the same as the habitats. Note, you must assign habitats on the basemap before setting each habitat as a region. To set each cell as a region, click the Make each cell a region button. Again, regions will automatically be updated on the basemap.
