5.4 Previous versions

Models built using EwE 5 (versions xx and later), can be converted to EwE 6 format using the Ecopath Database Conversion Wizard. When you select the old database using Open model on the File menu you will be prompted by the wizard to choose a model to extract from the old database. Select the model you wish to open and follow the prompts. EwE 6 will extract the model to a new database and save it in the same directory as the old EwE 5 database (or you can choose a new location).

Ecopath with Ecosim. Ecopath with Ecosim can only be run on PCs with a 32-bit operating system, such as Windows 95/98/Me/XP or Windows NT4/2000.
