9.4 Ecosim results

Select Ecosim results () after a run opens the Ecosim results form (Figure 9.2), which shows a result summary for the run, with start and end dates set using the vertical red lines in the Main upper panel (see above). If you wish to compare results from the beginning and end of the run, first move the vertical red lines accordingly.

You can choose to see results by fleet or by individual group. Results by individual group can be viewed by individual gears or by combined gears (selected using the drop-down menu).

Raw biomass results can be seen by exporting them to a csv file, using Export biomass results to .csv file on the Ecosim menu.
