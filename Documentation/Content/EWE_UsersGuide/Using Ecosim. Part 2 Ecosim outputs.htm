9 Using Ecosim. Part 2: Ecosim outputs

Once you have set up your Ecosim scenario(s) using the Ecosim input forms, you can test your model’s predictions using Ecosim. This chapter describes the forms used to run Ecosim (Biomass, Stock-Recruitment plot, Monte Carlo runs), as well as important Ecosim tools Fishing policy search and Fit to time series. An Ecosim exercise to help you test your model is also included.

Before using Ecosim, we recommend you read the introductory material on Ecosim (An overview of Ecosim, Ecosim basic, Predicting consumption, Time series fitting in Ecosim, Hints for fitting models to time series reference data and Time series random effects, also found in Chapter 1 of the User Guide). You should also be familiar with the published literature on Ecosim, particularly Walters et al. 1997; Walters et al. 2000 (Capabilities); MSY paper; Policy search papers…).
