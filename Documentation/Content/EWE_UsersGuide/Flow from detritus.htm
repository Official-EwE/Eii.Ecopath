7.23 Flow from detritus

The Trophic level decomposition analysis calculated the the fractions of the flow from each trophic level through each model group. The Flow from detritus analysis is equivalent, but calculates the flow from detritus through each group and converts it to absolute flows (t.km-2.year-1). The results are summarized in the Trophic aggregation analyses (see Flows and biomasses).
